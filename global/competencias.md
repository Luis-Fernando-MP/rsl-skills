# Ingeniería de Software — UTP

## ¿Qué hace un Ingeniero de Software?

Diseña y desarrolla soluciones tecnológicas —aplicaciones web, móviles y software empresarial— optimizando su rendimiento, seguridad y escalabilidad mediante metodologías y herramientas innovadoras.

## Áreas de desempeño

| Área                           | Descripción                                                                                 |
| ------------------------------ | ------------------------------------------------------------------------------------------- |
| **Desarrollo de aplicaciones** | Software a medida para plataformas web y móviles.                                           |
| **Desarrollo frontend**        | Diseño y construcción de interfaces, optimizando la experiencia de usuario.                 |
| **Desarrollo backend**         | Gestión de servidores, bases de datos y lógica de negocio.                                  |
| **Ciberseguridad**             | Implementación de medidas para proteger software y datos frente a amenazas.                 |
| **Desarrollo con IA**          | Sistemas de inteligencia artificial y automatización para optimizar procesos empresariales. |

## Competencias que desarrollarás

### 1. Soluciones informáticas

Desarrollo de aplicaciones con **PHP, HTML, CSS, JavaScript y MySQL**, y comprensión de cómo las organizaciones adoptan tecnologías digitales para mejorar operaciones, productos y servicios.

### 2. Desarrollo de software

Dominio de los procesos y entregables de cada etapa del ciclo de vida del software, junto con la gestión y planificación de proyectos reales.

### 3. Análisis de sistemas complejos

Identificación de requerimientos tecnológicos y uso de herramientas de modelado (**UML**). Incluye fundamentos teóricos de la computación: modelos formales, lenguajes formales y teoría de la complejidad, aplicados a la resolución de problemas computacionales profundos.

### 4. Tecnologías de vanguardia

Capacitación en tendencias globales: **inteligencia artificial, ciberseguridad, cloud computing** y desarrollo **Full Stack** y móvil.

### 5. Inteligencia de negocios (Business Intelligence)

Procesamiento y análisis de grandes volúmenes de datos mediante análisis predictivo y generación de reportes.

### 6. Gestión de proyectos tecnológicos

A través de cursos prácticos e integradores: liderazgo de proyectos de desarrollo de software desde la ideación hasta la entrega final, con énfasis en liderazgo, trabajo en equipo y gestión de la transformación digital.
